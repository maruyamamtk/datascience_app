# vNMの定理(フォン・ノイマン=モルゲンシュテルンの定理)

選択肢(くじ)についての選好関係 $\succeq$ が、次の4つの公理を満たすとする。

| 公理   | 内容                                               |
| ------ | -------------------------------------------------- |
| 完備性 | 任意の2つの選択肢を比較できる(無関係がない)        |
| 推移性 | $a\succeq b$ かつ $b\succeq c$ ならば $a\succeq c$ |
| 連続性 | 好みの連続性(急な選好の逆転がない)                 |
| 独立性 | 確率的混合における選好の独立性                     |

このとき、[効用関数](utility-function) $u$ が存在して、選択肢 $a$ が $b$ より好ましいことと
期待効用の大小が完全に一致する。

$$
a\succeq b \iff E[u(a)]\ge E[u(b)]
$$

- この $u$ は **カーディナル(基数的)** な尺度——正のアフィン変換 $u'=a\,u+b$($a>0$)を除いて一意。
- 定理は「公理を満たす選好関係が"存在するならば"効用関数で表現できる」という主張であり、
  «公理を満たさない意思決定者は不合理だ»と断じるものではない。公理からのズレをどう説明し、
  必要ならどう行動を変えるかが実務上は重要になる。
- 期待金額([期待値](expected-value))による意思決定は、$u(x)=x$(直線、[リスク態度](risk-attitude)が
  リスク中立)というvNM効用の特殊ケースにあたる。
