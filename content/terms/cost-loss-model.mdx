# コスト/ロスモデル

意思決定者が「対策する/しない」の2択を迫られる場面を、対策コスト $C$ とロス $L$ の2つの数字だけでモデル化したもの。

| 自然の状態 | 対策あり | 対策なし |
| ---------- | -------- | -------- |
| 危険な状態 | −C       | −L       |
| 安全な状態 | −C       | 0        |

- 対策すれば状態によらず必ずコスト $C$ がかかる。対策しなければ、危険な状態のときだけロス $L$ がかかる。
- [期待値](expected-value)で比較すると、対策の期待コストは $C$(一定)、対策しない場合は $p\cdot L$($p$=危険な状態になる確率)。対策する方が得になるのは $C<p\cdot L\iff p>C/L$。
- **最適閾値** $p^*=C/L$(コスト/ロス比)。確率予測 $\hat p\ge p^*$ なら対策するのが期待コスト最小の意思決定方式。
- [コスト考慮型学習](cost-sensitive-learning)の $p^*=C_{FP}/(C_{FP}+C_{FN})$ とは異なる利得構造(コスト考慮型学習は「誤ったときだけ」コストが発生するモデル、コスト/ロスモデルは「対策すれば常に」コストが発生するモデル)である点に注意。
- ユーザーごとにコスト比 $r=C/L$ が異なれば最適閾値も異なる——固定しきい値(0.5など)しか使えないカテゴリー予測と違い、確率予測はユーザーごとに最適な閾値を柔軟に設定できることが、確率予測の価値の源泉になる。
