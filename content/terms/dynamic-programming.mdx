# 動的計画法

大きな最適化問題を、**重なりのある部分問題**(同じ形の部分問題が繰り返し現れる)に分割し、各部分問題の最適解を1回だけ計算してテーブルに記録し(メモ化)、それを再利用しながら組み立てる手法。

- 適用できる条件は**最適性原理**(ベルマンの最適性原理)——「全体の最適解は、部分問題の最適解の組み合わせになっている」という性質。これが成り立たない問題には動的計画法は使えない。
- [マルコフ決定過程](markov-decision-process)のように、「今の状態から先」が毎回同じ形の問題として繰り返し現れる問題は、この条件を満たす典型例。
- 時間方向に「最後から遡って」部分問題を解いていく特殊な形が **[後ろ向き帰納法](decision-tree-analysis)**(バックワードインダクション)——[決定木](decision-tree-analysis)や、複数期間にわたる逐次決定問題(有限期間のMDP)を解くときに使う。
- 動的計画法の更新式は多くの場合 **[ベルマン方程式](bellman-equation)** の形(今の価値=今の報酬+残りの問題の最適価値)で書ける。

高校数学の「漸化式を使って数列の一般項を求める」発想の延長——ただし動的計画法では「同じ部分問題が何度も現れるので、1度計算したら表に書き留めて使い回す」という効率化が本質。愚直に再帰計算すると指数関数的に計算量が増える問題でも、動的計画法なら部分問題の数(状態数×時点数など)に比例する計算量で解けることが多い。
