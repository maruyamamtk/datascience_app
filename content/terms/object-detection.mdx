# 物体検出

[画像認識・分類](image-classification)が「画像全体に対して1つのクラスラベル」を予測するのに対し、物体検出は「画像の中の複数の物体それぞれ」について次の2つを同時に予測する、より難しいタスク。

- **位置**: 物体を囲む[バウンディングボックス](bounding-box)の座標（回帰問題）。
- **クラス**: そのボックスに写っている物体の種類（分類問題）。

代表的な処理の流れは次のようになる。

1. あらかじめ用意した多数の[アンカーボックス](anchor-box)（または候補領域）に対し、各アンカーが「物体らしいか」とその物体のクラス、正解ボックスへ合わせるための位置の微調整量を予測する。
2. 同じ物体に対して複数の重複した候補が残るため、[NMS（非最大値抑制）](non-maximum-suppression)で重複を間引き、1つの物体につき1つの検出結果に絞り込む。

**評価**: 予測ボックスと正解ボックスの[IoU](intersection-over-union)がしきい値以上なら「正しく検出できた」とみなし、その上で検出できたか・見逃したか（クラスの正誤も含む）を集計して[適合率・再現率](precision)のような指標で評価する（画像分類の評価とは異なり、「どこにあるか」の正しさもあわせて問われる点が特徴）。

学習の土台となる特徴抽出には[畳み込み層](convolutional-layer)を使ったCNNが使われることが多く、[転移学習](transfer-learning)で大規模データセットの事前学習済みモデルを流用するのも一般的。
