# 入力層・隠れ層・出力層

ニューラルネットワークは、ユニット（ニューロン）を **層** にまとめて並べた構造を持つ。

- **入力層**: 生のデータ（特徴量）をそのまま受け取る層。学習するパラメータは持たない。
- **隠れ層**: 入力層と出力層の間にある層。前の層の出力を[シナプス結合](synaptic-connection)（重み）で重み付けして足し合わせ、[活性化関数](activation-function)を通す——これを1つ以上重ねる。「隠れ」は外から直接観測できない中間表現という意味。
- **出力層**: 最終的な予測（回帰なら数値、分類ならクラスの確率など）を出す層。タスクに応じて活性化関数を変える（回帰は線形、2値分類はシグモイド、多クラス分類はソフトマックス）。

情報は入力層から出力層へ一方向に流れる（**順伝播**）。学習では逆に出力層から入力層へ向けて誤差の勾配を伝える（[誤差逆伝播法](backpropagation)）。この「値は前へ、勾配は後ろへ」という2方向の流れを、変数と演算をノードで表した[計算グラフ](computational-graph)として統一的に理解できる。

層を重ねる（深くする）ほど表現力は上がるが、[勾配消失](vanishing-gradient)が起きやすくなるなど学習の難しさも増す——「隠れ層をいくつ・何ユニットにするか」はネットワーク設計の中心的な問いになる。
