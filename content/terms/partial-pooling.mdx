# 部分プーリング

複数グループのデータをまとめて分析するときの3つの選択肢のうち、
[階層ベイズモデル](hierarchical-bayesian-model)が実現する«中間»の推定方法。

| 方法 | 各グループの推定値 | 弱点 |
|---|---|---|
| プールなし | 自グループの標本平均 $\bar y_j$ そのまま | サンプルサイズが小さいグループはノイズに弱い |
| 完全プール | 全グループ共通の平均 $\mu$ | グループ間の本当の違いを無視してしまう |
| **部分プーリング** | $\bar y_j$ と $\mu$ の**精度加重平均** | （階層ベイズモデルが自動的に«ちょうどよい»重みを決める） |

- 重みはハイパー事前分散 $\tau^2$（グループ間のばらつき）とサンプルサイズ $n_j$ で決まる。
  $\tau^2$ が大きい（グループは互いに無関係）ほどプールなしに近づき、
  $\tau^2$ が小さい（グループ間の差はほぼ無い）ほど完全プールに近づく。
- 同じグループ間分散 $\tau^2$ でも、サンプルサイズ $n_j$ が小さいグループほど部分プーリングは
  強く働く（[縮小推定](shrinkage-estimation)が大きくなる）——«データが少ないグループほど
  全体の情報に頼る» という直感を数式化したもの。
- ベイズ的には、$\theta_j$ の[事前分布](prior-distribution) $\mathcal N(\mu,\tau^2)$ と
  尤度を掛け合わせた事後平均として自然に導かれる（頻度論でも経験ベイズ法という形で同じ推定量が得られる）。
